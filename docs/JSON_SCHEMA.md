# Справочник по `data/site.json`

Файл состоит из трёх корневых объектов: `site`, `settings`, `blocks`.
JSON не поддерживает комментарии — подсказки живут здесь.

Пустое поле или отсутствующее поле = элемент не рисуется. Лишнее поле =
игнорируется (можно оставлять себе заметки, например `"comment": "цены с марта"`).

---

## 1. `site` — шапка, подвал, SEO

| Поле          | Тип      | Пример / назначение                                                              |
|---------------|----------|----------------------------------------------------------------------------------|
| `name`        | строка   | **Обязательно.** Название ресторана: подвал, `<title>`, schema.org               |
| `tagline`     | строка   | Подпись под логотипом в шапке («Ресторан средиземноморской кухни»)                |
| `title`       | строка   | Необязательно. Переопределить `<title>` вкладки (иначе «name — tagline»)          |
| `description` | строка   | Сниппет в поиске и карточке ссылки (1-2 предложения)                              |
| `url`         | строка   | `https://ваш-домен.ру` — для sitemap, canonical, schema.org, OG                   |
| `logoText`    | строка   | Текст логотипа в шапке (сама иконка-олива рисуется в index.html)                  |
| `lang`        | строка   | `ru` по умолчанию                                                                 |
| `phone`       | строка   | Отображаемый телефон `+7 (900) 000-00-00`                                         |
| `phoneHref`   | строка   | Телефон для набора: `+79000000000` (если не задать — очищается из `phone`)        |
| `email`       | строка   | Почта                                                                             |
| `address`     | строка   | Адрес строкой                                                                     |
| `mapUrl`      | строка   | Ссылка «Открыть на карте» (Яндекс/Google/2GIS)                                    |
| `currency`    | строка   | Символ валюты, по умолчанию `₽`                                                   |
| `cuisine`     | строка   | Для schema.org: «Средиземноморская»                                               |
| `priceRange`  | строка   | Для schema.org: `₽₽`                                                              |
| `legalNote`   | строка   | Добавка к копирайту в подвале (ИП, ООО)                                           |
| `social`      | массив   | `{ "label": "Telegram", "url": "https://t.me/..." }`                              |
| `nav`         | массив   | Пункты меню: `{ "label": "Меню", "target": "menyu" }`, где `target` — `id` блока  |
| `cta`         | объект   | Кнопка в шапке: `{ "label": "…", "target": "kontakty" }`                           |

`target` может быть `id` блока (`"menyu"`) или внешней ссылкой (`"https://…"`).

## 2. `settings` — дизайн без правки CSS

| Поле             | Тип    | По умолчанию | Назначение                                   |
|------------------|--------|--------------|----------------------------------------------|
| `colors.bg`      | цвет   | `#12100e`    | Фон страницы                                 |
| `colors.bgSoft`  | цвет   | `#1a1714`    | Фон «мягких» секций (через одну)             |
| `colors.card`    | цвет   | `#1e1a16`    | Фон карточек                                 |
| `colors.text`    | цвет   | `#f2ece2`    | Основной текст                               |
| `colors.muted`   | цвет   | `#a49b8d`    | Второстепенный текст                         |
| `colors.accent`  | цвет   | `#c9a227`    | Кнопки, акценты, цены-теги                   |
| `colors.accentText` | цвет | `#12100e`   | Текст на акцентном фоне                      |
| `colors.line`    | цвет   | `#2c2621`    | Линии, рамки                                 |
| `radius`         | число  | `14`         | Скругление углов, px                         |
| `maxWidth`       | число  | `1180`       | Ширина контейнера, px                        |
| `blockGap`       | число  | `96`         | Вертикальный отступ между блоками, px        |
| `imageRatio`     | строка | `"4 / 3"`    | Пропорции картинок по умолчанию              |
| `menuColumns`    | число  | `2`          | Колонок категорий в меню (ПК)                |
| `galleryColumns` | число  | `3`          | Колонок в галерее (ПК)                       |
| `teamColumns`    | число  | `3`          | Колонок в команде (ПК)                       |
| `animateOnScroll`| булево | `true`       | Плавное появление блоков при прокрутке       |
| `fontHead`       | строка | системный    | CSS-строка шрифта заголовков                 |
| `fontBody`       | строка | системный    | CSS-строка шрифта текста                     |

Цвета принимают любой CSS-формат: `#c9a227`, `rgb(...)`, `oklch(...)`.
Светлая тема = просто другой набор цветов, HTML не меняется.

## 3. Общие поля блока

| Поле      | Тип    | Назначение                                                                    |
|-----------|--------|-------------------------------------------------------------------------------|
| `id`      | строка | Якорь для меню (`#menyu`). Должен быть уникальным. Можно не писать — сделается из заголовка |
| `type`    | строка | Один из: `hero`, `text-image`, `text`, `promo`, `menu`, `gallery`, `team`, `contacts` |
| `visible` | булево | `false` — блок скрыт (удобно для сезонных акций). По умолчанию виден         |
| `bg`      | строка | Фон секции: `""` обычный, `"soft"` приглушённый, `"accent"` акцентный градиент |
| `eyebrow` | строка | Надзаголовок мелким капсом                                                    |
| `title`   | строка | Заголовок секции                                                              |
| `subtitle`| строка | Подзаголовок                                                                  |
| `center`  | булево | Центрировать заголовок (для menu/gallery/team/contacts)                       |

Кнопки везде одинаковые: `{ "label": "Текст", "target": "id или url", "style": "primary" | "ghost" | "light" }`.

Картинки везде одинаковые: объект `{ "src", "alt", "caption", "ratio", "overlay", "eager" }`
или просто строка-путь.

- `src` — путь от корня сайта (`assets/img/x.jpg`) или внешний `https://…`
- `alt` — описание для поиска и скринридеров (проверяется утилитой)
- `caption` — подпись поверх нижнего края
- `ratio` — пропорции именно этой картинки (`"16 / 9"`, `"1 / 1"`)
- если рядом с `.jpg`/`.png` лежит файл с тем же именем и расширением `.webp`,
  браузер автоматически получит webp (он легче). В JSON пишите `.jpg`.

## 4. Типы блоков

### `hero` — первый экран
Фото на весь экран, затемнение, заголовок, кнопки, строка фактов.

```jsonc
{
  "id": "hero", "type": "hero",
  "eyebrow": "с 2012 года",
  "title": "Вкус Средиземноморья в центре города",
  "text": "Одно предложение-крючок.",
  "image": { "src": "assets/img/hero.jpg", "alt": "Зал вечером", "overlay": 0.55 },
  "buttons": [ { "label": "Посмотреть меню", "target": "menyu", "style": "primary" },
               { "label": "Забронировать стол", "target": "kontakty", "style": "ghost" } ],
  "facts": [ { "value": "13", "label": "лет работы" } ]
}
```
`overlay` (0…1) — сила затемнения фото под текстом. `facts` — до 4 пар значение/подпись.

### `text-image` — конструктор «текст + картинка»
```jsonc
{
  "id": "o-nas", "type": "text-image",
  "imagePosition": "left",            // "left" | "right"; без поля или без image — текст по центру
  "title": "О ресторане",
  "text": "Абзац 1.\n\nАбзац 2.",      // \n\n = новый абзац
  "image": { "src": "assets/img/about.jpg", "alt": "…", "caption": "Шеф Марк" },
  "features": ["Пункт списка 1", "Пункт 2"],
  "buttons": [ … ]
}
```
На смартфоне картинка всегда сверху, текст под ней — так читабельнее.

### `text` — текст по центру (без картинки)
`{ "type": "text", "title", "subtitle", "text" }` + общий `bg`.

### `promo` — акция
```jsonc
{
  "id": "akcii", "type": "promo",
  "label": "Акция до 31 октября",      // жёлтый бейдж
  "title": "Сет «Дегустация» за 2 490 ₽ вместо 3 200 ₽",
  "text": "Условия акции.",
  "image": { "src": "assets/img/promo.jpg", "alt": "…" },
  "buttons": [ … ]
}
```

### `menu` — цены
```jsonc
{
  "id": "menyu", "type": "menu",
  "title": "Меню",
  "subtitle": "Цены действительны с 1 сентября.",
  "columns": 2,                         // необязательно, переопределяет settings.menuColumns
  "categories": [
    { "name": "Холодные закуски",
      "items": [
        { "name": "Тартар из тунца",
          "description": "авокадо, юдзу, кунжут",
          "price": 890,                 // число; форматируется автоматически («890 ₽»)
          "oldPrice": null,             // число > price — рисуется зачёркнутым
          "tags": ["хит"] }             // см. ниже
      ] }
  ],
  "note": "Полная карта — у официанта."
}
```
Теги с особым стилем: `хит` (латунный), `акция` (заливка), `veg` (зелёный).
Любой другой текст тега рисуется нейтрально.

### `gallery` — сетка фото
`{ "type": "gallery", "title", "subtitle", "columns": 3, "ratio": "4 / 3",
   "images": [ { "src", "alt", "caption" }, … ] }`
Клик по фото открывает его крупно (лайтбокс). На телефонах подписи видны всегда.

### `team` — команда
`{ "type": "team", "title", "people": [ { "name", "role", "text", "photo": "assets/img/komanda-1.svg" } ] }`

### `contacts` — контакты и часы
```jsonc
{
  "id": "kontakty", "type": "contacts",
  "title": "Контакты и часы работы",
  "schedule": [ { "days": "Понедельник — четверг", "hours": "12:00 — 00:00" } ],
  "extra": ["Бизнес-ланч по будням 12:00—16:00"],
  "image": { "src": "assets/img/karta.svg", "alt": "Схема проезда" },
  "mapUrl": "https://yandex.ru/maps/?text=…"   // если не задать — берётся site.mapUrl
}
```
Телефон, почта и адрес подставляются из `site` автоматически.

## 5. Частые рецепты

**Сезонная акция «включить/выключить»:** у блока акции `"visible": true|false`.

**Вторая акция:** скопируйте блок `promo`, задайте другой `id` (например `akcii-2`)
и поставьте его в нужное место массива `blocks`.

**Блок «только текст по центру»:** `text-image` без поля `image`
(или тип `text`, если не нужны кнопки/списки).

**Поменять сторону картинки:** `"imagePosition": "right"`.

**Свои шрифты:** положите файлы в `assets/fonts/`, подключите в `style.css`
через `@font-face` и укажите семейство в `settings.fontHead` / `settings.fontBody`.
